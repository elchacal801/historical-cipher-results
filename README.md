# Historical Cipher Lab — public results

Working title. This repository will publish reviewed historical cipher research with sources, reproducible methods, attribution and explicit uncertainty.

No completed historical decipherment is included in this initial scaffold. Each future case will state whether it is a new cryptanalytic recovery, known-key application, recovered archival decipherment, partial reconstruction, replication, or negative result.

Only reviewed release bundles belong here. Private notes, restricted scans and development history are maintained separately. Source institutions and prior researchers retain their own rights and credit.

Use the structured issue templates for source leads and corrections. A proposed plaintext should include its key or algorithm, ciphertext alignment and reproducible evidence. Please do not submit executable attachments or private documents through public issues.
