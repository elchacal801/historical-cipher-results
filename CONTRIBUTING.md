# Contributing

Provide an archive identifier, stable source link, exact claim, prior work and reproducible method. Explain uncertainty and changes made to source text. Distinguish transcription corrections from decipherment and historical reconstruction.

Credit transcribers, key discoverers, software authors, archives, reviewers and model assistance. Do not assert that a target has never been solved solely because a catalogue says “unsolved.”

Do not post restricted scans, credentials, personal correspondence or material you lack permission to distribute. Submitted code is reviewed before execution. Contributions of original code are accepted under MIT and original prose under CC BY 4.0, as described in LICENSE-MAP.md. Respectful criticism and reproducible corrections are welcome.
