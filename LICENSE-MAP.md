# Licence map

Decided by the repository owner on 2026-10-03.

| Material | Licence | Full text |
|---|---|---|
| Original code written for this project (scripts, tools, reproduction code) | MIT | `LICENSE` |
| Original prose written for this project (case reports, methods notes, documentation) | CC BY 4.0 | `LICENSE-DOCS` |
| Third-party material (source images, transcriptions, datasets, software, quotations) | Not relicensed; each asset keeps its own terms | Recorded per case release |

Neither licence applies to third-party material. Source institutions, transcribers, key discoverers and software authors keep their own rights and credit. Historical age alone does not settle reuse terms for a modern scan.

Each case release must list which licence applies to each asset. Material without a clear redistribution basis stays out of this repository; the public bundle gives a source locator or access instructions instead.
